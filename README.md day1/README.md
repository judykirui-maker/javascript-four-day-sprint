# JavaScript Four-Day Sprint

## Project Overview
This repository documents my learning journey through a four-day JavaScript practical training sprint. During this sprint, I will learn JavaScript fundamentals and use them to build a Focus Board task planner.

## Learning Objectives
- Understand JavaScript variables, values, operators, and functions.
- Learn how to use arrays, objects, and array methods.
- Understand the DOM and handle user events.
- Use localStorage to save tasks in the browser.
- Learn asynchronous JavaScript using Promises, async/await, and fetch.
- Build a working task planner using HTML, CSS, and JavaScript.

## Four-Day Learning Plan
- **Day 1:** JavaScript fundamentals, conditions, loops, functions, and debugging.
- **Day 2:** Arrays, objects, array methods, and object-oriented programming.
- **Day 3:** DOM manipulation, events, form validation, and localStorage.
- **Day 4:** Promises, async/await, fetch, and the Focus Board project.

## Final Project
The final project will be a Focus Board task planner that allows users to create, manage, complete, search, and filter tasks. Tasks will be saved in the browser so they can be recovered later.
